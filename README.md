# aituner-app/homebrew-tap

Homebrew casks for [aituner](https://aituner.app/): benchmark Apple Silicon Macs for local AI.

```sh
brew install --cask aituner-app/tap/aituner
```

The cask arrives with aituner's first release and is updated by each release after it; every release is signed with a
Developer ID and notarized.
